    Class XMLDSigToken

    An XML token: an enveloping XML digital signature that holds timestamped user data, optionally encrypted. The counterpart of the class XMLDSigToken of the PHP library ezxmldsig: both create and verify the same tokens.

    Get an instance with one of the factories, createXMLToken() to create a token, analyzeXMLToken() to analyze one. An analysis requires a trust anchor (options caCertPath and/or signerCertPath): without it, no token is valid.

    isSignatureValid() checks neither the freshness of the token nor whether it is replayed. Before trusting the data of a received token, the receiver must check that isSignatureValid() returns true, that isOutOfDate(ttl) returns false, and that the identifier returned by getTokenId() has not been accepted before (store it atomically, and refuse the token if it already is).

    • isSignatureValid(): boolean

          cryptKeyPath: PemSource,

          options?: TokenOptions,

      Analyzes an XML token whose data are encrypted, with the private key of the recipient. An unencrypted token can also be analyzed this way.

      The token is only decrypted once its structure, its algorithms, its digest, its signature and the trust in its certificate have been verified, and every failure of the decryption gives the same error, Token decryption failed!.

      Parameters

      • xml: string | Uint8Array<ArrayBufferLike>

        The XML token, as a string or as the bytes of its UTF-8 encoding.

      • cryptKeyPath: PemSource

        The private key of the recipient, in PEM format: the path of its file, or its content.

      • cryptKeyPassword: string | null = null

        The password of this key, if any.

      • options: TokenOptions = {}

        The options, trust anchor included (see the README).

      Returns XMLDSigToken

    StaticcreateSecureXMLToken

    • createSecureXMLToken(
          data: TokenData,
          signKeyPath: PemSource,
          signCertPath: PemSource,
          cryptKeyPath: PemSource | null,
          cryptCertPath: PemSource,
          signKeyPassword?: string | null,
          cryptKeyPassword?: string | null,
          options?: TokenOptions,
      ): XMLDSigToken

      Creates a signed token whose data are encrypted for the owner of the encryption certificate: only the private key of this certificate decrypts them. The sender does not need this private key: pass null as cryptKeyPath.

      The created token is checked right away. Without cryptKeyPath, the check covers everything that can be verified without decrypting the token (structure, algorithms, digest, signature, trust in the signing certificate): isSignatureValid() and isDataEncrypted() return true, while getData(), getTimestamp(), getTokenId(), getAudience() and getExpiry() return null. With cryptKeyPath, the token is also decrypted and its content read.

      Parameters

      • data: TokenData

        The token data (see createXMLToken()).

      • signKeyPath: PemSource

        The private key that signs the token, in PEM format.

      • signCertPath: PemSource

        The X.509 certificate of this key, in PEM format.

      • cryptKeyPath: PemSource | null

        The private key of the recipient, in PEM format, to check the content of the created token; null without it.

      • cryptCertPath: PemSource

        The encryption certificate of the recipient, in PEM format.

      • signKeyPassword: string | null = null

        The password of the signing key, if any.

      • cryptKeyPassword: string | null = null

        The password of the private key of the recipient, if any (null without cryptKeyPath).

      • options: TokenOptions = {}

        The options (see the README).

      Returns XMLDSigToken

    • createXMLToken(

          signKeyPath: PemSource,
          signCertPath: PemSource,

      Creates an XML token for the given user data.

      The created token is analyzed right away to check it, with the certificate of its own signing key as trust anchor. If it cannot be created, getError() tells why; a parameter or an option that is refused throws.

      Parameters

      • data: TokenData

        The token data: named values, nested at will. A value is a string, a number, a boolean, null (written as an empty string), or bytes (a Uint8Array).

      • signKeyPath: PemSource

        The private key that signs the token, in PEM format: the path of its file, or its content.

      • signCertPath: PemSource

        The X.509 certificate of this key, in PEM format, included in the token: the path of its file, or its content.

      • signKeyPassword: string | null = null

        The password of the private key, if any.

      • options: TokenOptions = {}

        The options (see the README).

      Returns XMLDSigToken
